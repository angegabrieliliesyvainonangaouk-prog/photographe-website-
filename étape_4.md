    le rapport Lighthouse au vert sur la partie SEO (note supérieure ou égale à 90 %).

 

Recommandations : 

    Choisissez au niveau du code ce qui vous semble le plus pertinent pour l’optimisation : sémantique, optimisation du CSS / JS, etc.
    Il n’y a pas une seule bonne réponse à prendre en compte pour le SEO technique : à vous de choisir si vous souhaitez optimiser le code JavaScript ou CSS, si vous souhaitez travailler la sémantique, etc. Cependant, pensez à annoter toutes vos modifications afin de préparer au fur et à mesure votre rapport d’intervention.
